# Security policy

DOT does not execute cadata contents; they are parsed as data. Treat campaign and conductor files
from untrusted sources cautiously and review resolved paths before running a campaign.

Please report suspected security problems privately to the repository owner rather than opening a
public issue. Include the DOT version, platform, minimal reproducer, and impact. This research
software is not a safety system and must not be used as the sole basis for magnet protection or
personnel-safety decisions.
